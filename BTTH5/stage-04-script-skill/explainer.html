Stage 04: Script skill

Stage 04 giữ nguyên ba tool của Stage 03 (read_file, write_file, bash) và không đổi code agent. Điều mới là skill csv-quality có thư mục scripts/ chứa check_csv.py. Agent đọc SKILL.md để biết lệnh, chạy script qua bash, rồi ghi báo cáo vào output/.

2Workspace

Mọi file của agent nằm trong thư mục workspace/. Bấm vào một file để xem nội dung thật và cách agent dùng file đó.

name, description, location. Luôn nằm trong system prompt (catalog).

8Bảo mật

  
Code của stage này giới hạn tool theo ba cách: kiểm tra đường dẫn (read_file, write_file), giới hạn tiến trình (bash) và giới hạn số lần gọi (middleware). Bash không phải sandbox. Các phần dưới cho thấy chỗ nào bị chặn và chỗ nào không.


  

    
Kiểm tra đường dẫn của read_file và write_file dữ liệu thật

    
Hàm _resolve(), _read(), _write() trong tools/files.py, viết lại bằng JavaScript trên một workspace giả lập (các file lấy từ cây ở phần 2, thêm hai file giả lập để thử giới hạn). Chọn tool, gõ đường dẫn hoặc bấm một mẫu.

9Trace JSONL

  
Mỗi lượt chat ghi một file trong traces/ theo mẫu <thời gian>_<conversation>_turnNN_<run>.jsonl. Mỗi dòng là một event. Thư mục traces/ của stage này hiện chỉ có .gitkeep, nên các dòng bên dưới là minh hoạ: tên trường lấy từ observer.py, dữ liệu dựng từ prompt thử trong README và kết quả chạy thật của script.
