Stage 03: Bash

Stage 03 thêm tool bash vào agent của Stage 02. Agent có ba tool (read_file, write_file, bash) và một skill (weekly-report). Tool bash chạy lệnh bash -c trong thư mục workspace rồi trả về stdout, stderr và exit code. Bash không phải sandbox: giới hạn path của hai file tool không áp dụng cho bash. 1Kiến trúc

Bấm vào từng khối để xem file tương ứng và nhiệm vụ của nó. Khối viền cam là phần mới so với Stage 02: file tools/bash.py, dòng TOOLS = [read_file, write_file, bash] trong agent.py và đoạn mô tả bash trong prompts.py. Các file còn lại giữ nguyên.

2Ba tool

Chọn một tool để xem tham số, kết quả, mã lỗi và schema mà model nhận được. Điểm khác chính: file tool trả lỗi khi vi phạm quy tắc path, còn bash coi mọi lệnh đã chạy xong là ok: true, kể cả khi exit code khác 0.

5Giới hạn và sandbox

  
Phần này tách rõ cái code thực sự áp dụng khỏi cái code không áp dụng. Tool bash có cwd, env, timeout và giới hạn output. Tool bash không có path sandbox, không lọc lệnh và không giới hạn tài nguyên.


  

    
Bảng cơ chế

    

    
Bash không phải sandbox. Lệnh vẫn đọc và ghi được ngoài workspace với quyền của user chạy app. Chỉ chạy lab với dữ liệu giả, không mount thư mục cá nhân hoặc secrets vào máy chạy lab (README, mục Giới hạn môi trường).
