Bấm vào từng khối để xem file tương ứng và nhiệm vụ của nó. Khối có nhãn mới là phần Stage 01 bổ sung so với Stage 00.

2Tool

3Path sandbox

Mọi path đi qua hàm _resolve() trong tools/files.py trước khi tool đọc hoặc ghi. Phần này chạy lại cùng chuỗi kiểm tra trên một workspace giả lập trong trang. Chọn tool, chọn một mẫu hoặc nhập path rồi bấm Chạy.

Logic kiểm tra lấy từ tools/files.py dữ liệu thật. Các file big.txt, bin.dat, link.txt, thư mục symlink output/escape và secret.txt không có trong workspace thật. Chúng được thêm theo các test trong tests/test_files.py để có thể thử từng lỗi minh hoạ.

App đọc cấu hình từ file .env của project. Bật hoặc tắt từng biến để xem giao diện phản ứng thế nào khi thiếu cấu hình.

Endpoint cần hỗ trợ tool calling theo chuẩn OpenAI Chat Completions (tools, tool_calls, message role tool). App không truyền temperature hay tham số nào khác. API key không được ghi vào trace hay log.

    

  





Nguồn: agent.py, config.py, prompts.py, paths.py, observer.py, trace.py, reset_workspace.py, tools/files.py, app.py, README.md, tests/ và dữ liệu trong workspace/ của project này. Giới hạn của hai middleware được đối chiếu với mã nguồn thư viện langchain đã cài trong .venv. Nhãn dữ liệu thật là dữ liệu lấy từ code, test hoặc README. Nhãn minh hoạ là phần mô phỏng. Project chưa có file trace, nên mọi kịch bản chạy agent trong trang này đều là mô phỏng.
